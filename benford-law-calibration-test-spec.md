# Benford's Law Calibration Test — Specification for Claude Code

## Background

Benford's Law predicts that the leading digits of numbers in naturally occurring datasets follow a logarithmic distribution. The law generalizes across multiple digit positions:

**First digit (D1):** P(d₁) = log₁₀(1 + 1/d₁) for d₁ ∈ {1,...,9}. Digit 1 appears ~30.1%, digit 9 ~4.6%.

**Second digit (D2):** P(d₂) = Σ(d₁=1 to 9) log₁₀(1 + 1/(10·d₁ + d₂)) for d₂ ∈ {0,...,9}. More uniform than D1 but still not flat — digit 0 appears ~11.97%, digit 9 ~8.50%.

**First-two digits (D1D2):** P(d₁d₂) = log₁₀(1 + 1/(d₁d₂)) for d₁d₂ ∈ {10,...,99}. This is the most powerful forensic test — 90 possible values provide far more statistical granularity than 9.

**General nth digit:** As digit position increases, the distribution converges toward uniform. By the 4th-5th digit, each digit 0-9 appears roughly 10% of the time. The rate of convergence from Benford toward uniform is itself a signature of genuine multiplicative processes.

### Why Multi-Digit Testing Matters

The first-digit test has only 9 bins. It catches gross manipulation but misses threshold gaming — a company rounding $48M transactions up to $50M would barely register as a "digit 4 deficit / digit 5 excess" in a 9-bin test. The first-two-digit test catches it clearly as a spike at "48" and "49" with a deficit at "50" and "51."

Nigrini's forensic accounting work considers the first-two-digit test the most practical for real-world fraud detection because financial manipulation often targets specific thresholds: analyst consensus estimates, loan covenants, round-number revenue targets, purchase approval cutoffs.

The second-digit test independently validates the first-digit test. Research shows fabricated numbers sometimes produce plausible first-digit distributions but fail on the second digit — humans intuitively grasp that "1" should be common as a leading digit but don't maintain the correct second-digit distribution.

The digit convergence pattern (how quickly the distribution becomes uniform across digit positions) provides a structural fingerprint. Genuine multiplicative data shows strong D1 Benford conformity, moderate D2 conformity, and near-uniform D3+. Fabricated data often shows too much uniformity in early digits (humans make all digits roughly equal) or too little uniformity in later digits (systematic patterns in specific digit positions).

### Financial Statement Research

Research by Amiram, Bozanic, and Rouen found that financial statements as a whole conform to Benford's distribution, and that companies whose filings deviate were 30% more likely to have adverse SOX 302 opinions, 45% more likely to have adverse 404 opinions, and 50% more likely to file non-timely reports. Benford deviation has detected fraud at Enron, WorldCom, HealthSouth, and Tyco, and is admissible in US courts.

### Complex Systems Research

Recent research (PLOS ONE 2025, Sen & Sen 2011) shows that Benford conformity correlates with system health — ecological systems in balanced dynamic equilibrium conform to Benford, while systems approaching state transitions show increasing Kullback-Leibler divergence. Physicists demonstrated that Benford deviation detects phase transitions with better scaling exponents than traditional measurements.

## Hypotheses

### Defensive (Data Quality and Fraud Detection)

1. **Companies with unreliable or manipulated financial data will show higher Benford deviation** than companies with clean reporting. The first-two-digit test will catch threshold manipulation the first-digit test misses.

2. **Value traps may include companies with manipulated financials.** Multi-digit Benford analysis could catch these before the framework wastes attractor analysis on bad data.

### Offensive (Opportunity Detection)

3. **Companies with genuine DKS flywheels (winners) will show better Benford conformity across all digit tests** than traps, because their financial data is generated by real multiplicative growth processes.

4. **Companies whose flywheels are strengthening will show improving KL divergence over time** — a leading indicator of DKS health.

5. **Companies approaching dissolution will show worsening KL divergence** before the stock price or qualitative analysis catches the deterioration.

6. **Sectors undergoing structural regime shifts will show aggregate Benford deviation** as the old equilibrium breaks.

7. **Winner companies will show the correct digit convergence pattern** (strong D1 Benford → moderate D2 → near-uniform D3+), while traps will show disrupted convergence — either too uniform early (fabrication) or too non-uniform late (systematic manipulation).

// ============================================
// FIRST DIGIT TEST (9 bins, d1 = 1 to 9)
// ============================================
function benfordFirstDigit(numbers) {
  const digits = numbers
    .map(n => Math.abs(n))
    .filter(n => n > 0)
    .map(n => parseInt(n.toExponential().charAt(0)))
    .filter(d => d >= 1 && d <= 9);

  if (digits.length < 50) return null;

  const observed = new Array(9).fill(0);
  digits.forEach(d => observed[d - 1]++);
  const total = digits.length;

  const expected = [];
  for (let d = 1; d <= 9; d++) {
    expected.push(Math.log10(1 + 1 / d));
  }

  return computeStats(observed, expected, total, 'first_digit');
}

// ============================================
// SECOND DIGIT TEST (10 bins, d2 = 0 to 9)
// ============================================
function benfordSecondDigit(numbers) {
  const digits = numbers
    .map(n => Math.abs(n))
    .filter(n => n >= 10) // Need at least 2 significant digits
    .map(n => {
      // Extract second significant digit
      const s = n.toPrecision(2);
      return parseInt(s.replace('.', '').charAt(1));
    })
    .filter(d => d >= 0 && d <= 9);

  if (digits.length < 50) return null;

  const observed = new Array(10).fill(0);
  digits.forEach(d => observed[d]++);
  const total = digits.length;

  // Benford's second digit expected frequencies
  const expected = [];
  for (let d2 = 0; d2 <= 9; d2++) {
    let p = 0;
    for (let d1 = 1; d1 <= 9; d1++) {
      p += Math.log10(1 + 1 / (10 * d1 + d2));
    }
    expected.push(p);
  }

  return computeStats(observed, expected, total, 'second_digit');
}

// ============================================
// FIRST-TWO DIGITS TEST (90 bins, d1d2 = 10 to 99)
// ============================================
function benfordFirstTwoDigits(numbers) {
  const twoDigits = numbers
    .map(n => Math.abs(n))
    .filter(n => n >= 10)
    .map(n => {
      // Extract first two significant digits
      const s = n.toPrecision(2);
      return parseInt(s.replace('.', '').substring(0, 2));
    })
    .filter(d => d >= 10 && d <= 99);

  if (twoDigits.length < 200) return null; // Need more data for 90 bins

  const observed = new Array(90).fill(0);
  twoDigits.forEach(d => observed[d - 10]++);
  const total = twoDigits.length;

  const expected = [];
  for (let d = 10; d <= 99; d++) {
    expected.push(Math.log10(1 + 1 / d));
  }

  const stats = computeStats(observed, expected, total, 'first_two_digits');

  // Identify specific threshold spikes (top 5 most over-represented two-digit combos)
  const deviations = [];
  for (let i = 0; i < 90; i++) {
    deviations.push({
      digits: i + 10,
      observed: observed[i] / total,
      expected: expected[i],
      deviation: (observed[i] / total) - expected[i],
      zScore: ((observed[i] / total) - expected[i]) /
              Math.sqrt(expected[i] * (1 - expected[i]) / total)
    });
  }
  deviations.sort((a, b) => Math.abs(b.zScore) - Math.abs(a.zScore));
  stats.topAnomalies = deviations.slice(0, 10);

  // Flag threshold patterns
  stats.thresholdFlags = [];
  // Check for spikes just below round numbers (48-49 spike = $50 threshold gaming)
  const roundNumbers = [20, 25, 30, 40, 50, 75, 99];
  for (const threshold of roundNumbers) {
    if (threshold - 1 >= 10 && threshold - 1 <= 99) {
      const idx = threshold - 1 - 10;
      const below = deviations.find(d => d.digits === threshold - 1);
      const at = threshold <= 99 ? deviations.find(d => d.digits === threshold) : null;
      if (below && below.zScore > 2.0) {
        stats.thresholdFlags.push({
          threshold,
          belowDigits: threshold - 1,
          belowZScore: below.zScore,
          atZScore: at ? at.zScore : null,
          pattern: `Spike at ${threshold - 1}, possible ${threshold * (threshold < 100 ? 1 : 1)}x threshold gaming`
        });
      }
    }
  }

  return stats;
}

// ============================================
// THIRD DIGIT TEST (10 bins, d3 = 0 to 9) — for convergence analysis
// ============================================
function benfordThirdDigit(numbers) {
  const digits = numbers
    .map(n => Math.abs(n))
    .filter(n => n >= 100) // Need at least 3 significant digits
    .map(n => {
      const s = n.toPrecision(3);
      return parseInt(s.replace('.', '').charAt(2));
    })
    .filter(d => d >= 0 && d <= 9);

  if (digits.length < 50) return null;

  const observed = new Array(10).fill(0);
  digits.forEach(d => observed[d]++);
  const total = digits.length;

  // Third digit expected: closer to uniform but still slightly Benford
  // General formula for nth digit is complex; for practical purposes,
  // compute from the joint distribution
  const expected = [];
  for (let d3 = 0; d3 <= 9; d3++) {
    let p = 0;
    for (let d1 = 1; d1 <= 9; d1++) {
      for (let d2 = 0; d2 <= 9; d2++) {
        p += Math.log10(1 + 1 / (100 * d1 + 10 * d2 + d3));
      }
    }
    expected.push(p);
  }

  return computeStats(observed, expected, total, 'third_digit');
}

// ============================================
// SHARED STATISTICS FUNCTION
// ============================================
function computeStats(observed, expected, total, testName) {
  const k = observed.length;

  // KL divergence
  let kld = 0;
  for (let i = 0; i < k; i++) {
    const p = observed[i] / total;
    const q = expected[i];
    if (p > 0 && q > 0) {
      kld += p * Math.log(p / q);
    }
  }

  // Mean Absolute Deviation
  let mad = 0;
  for (let i = 0; i < k; i++) {
    mad += Math.abs((observed[i] / total) - expected[i]);
  }
  mad /= k;

  // Chi-square
  let chiSq = 0;
  for (let i = 0; i < k; i++) {
    const exp = expected[i] * total;
    const obs = observed[i];
    chiSq += ((obs - exp) ** 2) / exp;
  }
  const chiSqDF = k - 1;
  // Critical values at p=0.05: df=8 → 15.507, df=9 → 16.919, df=89 → 112.022
  const chiSqCritical = {8: 15.507, 9: 16.919, 89: 112.022}[chiSqDF] || null;
  const chiSqSignificant = chiSqCritical ? chiSq > chiSqCritical : null;

  // Nigrini MAD thresholds vary by test type
  let conformity;
  if (testName === 'first_digit') {
    // Nigrini first-digit thresholds
    if (mad < 0.006) conformity = 'close';
    else if (mad < 0.012) conformity = 'acceptable';
    else if (mad < 0.015) conformity = 'marginal';
    else conformity = 'non-conforming';
  } else if (testName === 'second_digit') {
    // Nigrini second-digit thresholds (tighter)
    if (mad < 0.008) conformity = 'close';
    else if (mad < 0.010) conformity = 'acceptable';
    else if (mad < 0.012) conformity = 'marginal';
    else conformity = 'non-conforming';
  } else if (testName === 'first_two_digits') {
    // Nigrini first-two-digit thresholds (tightest — 90 bins)
    if (mad < 0.0012) conformity = 'close';
    else if (mad < 0.0018) conformity = 'acceptable';
    else if (mad < 0.0022) conformity = 'marginal';
    else conformity = 'non-conforming';
  } else {
    // Third digit and beyond — no standard thresholds, use uniform deviation
    const uniformDev = Math.abs(mad - 0);
    conformity = uniformDev < 0.005 ? 'near-uniform' : 'deviating';
  }

  // Per-bin deviations
  const digitDeviations = observed.map((c, i) => ({
    bin: testName === 'first_digit' ? i + 1 :
         testName === 'first_two_digits' ? i + 10 : i,
    observed: c / total,
    expected: expected[i],
    deviation: (c / total) - expected[i],
    zScore: ((c / total) - expected[i]) /
            Math.sqrt(expected[i] * (1 - expected[i]) / total)
  }));

  return {
    testName, kld, mad, chiSq, chiSqDF, chiSqSignificant, conformity,
    n: total, observed: observed.map(c => c / total), expected, digitDeviations
  };
}

// ============================================
// DIGIT CONVERGENCE ANALYSIS
// ============================================
function digitConvergenceProfile(numbers) {
  const d1 = benfordFirstDigit(numbers);
  const d2 = benfordSecondDigit(numbers);
  const d3 = benfordThirdDigit(numbers);

  if (!d1 || !d2) return null;

  // Measure how quickly the distribution converges toward uniform
  // Use KLD from uniform as the measure at each digit position
  const uniformKLD = (observed, k) => {
    const uniform = 1 / k;
    let kld = 0;
    for (let i = 0; i < observed.length; i++) {
      if (observed[i] > 0) {
        kld += observed[i] * Math.log(observed[i] / uniform);
      }
    }
    return kld;
  };

  const d1_uniformKLD = uniformKLD(d1.observed, 9);
  const d2_uniformKLD = uniformKLD(d2.observed, 10);
  const d3_uniformKLD = d3 ? uniformKLD(d3.observed, 10) : null;

  // Expected pattern for genuine multiplicative data:
  // D1 far from uniform (high KLD from uniform, ~0.11)
  // D2 closer to uniform (lower KLD, ~0.003)
  // D3 very close to uniform (KLD < 0.001)
  // Convergence ratio: d2_uniformKLD / d1_uniformKLD should be << 1

  const convergenceRatio = d2_uniformKLD / d1_uniformKLD;

  return {
    d1_benfordKLD: d1.kld,    // How well D1 matches Benford (lower = better)
    d2_benfordKLD: d2.kld,    // How well D2 matches Benford
    d1_uniformKLD,             // How far D1 is from uniform (higher = more Benford-like)
    d2_uniformKLD,             // How far D2 is from uniform
    d3_uniformKLD,             // How far D3 is from uniform (should be very low)
    convergenceRatio,          // d2/d1 — lower = faster convergence toward uniform = more natural
    d1_conformity: d1.conformity,
    d2_conformity: d2.conformity,
    d3_conformity: d3 ? d3.conformity : 'insufficient data',
    // Flag abnormal patterns
    flags: [
      // D1 too uniform → possible fabrication (humans make digits roughly equal)
      ...(d1_uniformKLD < 0.05 ? ['D1_TOO_UNIFORM: First digits suspiciously close to uniform distribution — possible fabrication'] : []),
      // D2 fails but D1 passes → sophisticated manipulation
      ...(d1.conformity !== 'non-conforming' && d2.conformity === 'non-conforming' ?
        ['D2_FAILS_D1_PASSES: Second digit non-conforming despite acceptable first digit — possible sophisticated manipulation'] : []),
      // D3 not converging → systematic pattern in later digits
      ...(d3 && d3_uniformKLD > 0.01 ? ['D3_NOT_CONVERGING: Third digit still far from uniform — possible systematic digit manipulation'] : []),
      // Convergence too fast → all digits too uniform → fabricated
      ...(convergenceRatio > 0.8 ? ['FLAT_CONVERGENCE: Digits not converging naturally — distribution too uniform across all positions'] : []),
    ]
  };
}

**If Test 5 passes:** Add Benford trend monitoring to the sell engine as a dissolution early warning.

**If Test 8 passes:** Weight Growth sector signals by order-of-magnitude position.

### Metric Selection

The tests will reveal which digit level is most useful. The report should explicitly recommend one primary Benford metric for the framework based on which test level produced the best combined results across discrimination (Test 3), temporal signal (Tests 4-5), and fraud detection (Test 2). Possibilities:

- **D1 KLD** — simplest, requires least data, may be sufficient
- **D1D2 KLD** — most granular, best for fraud, needs more data per company
- **Convergence ratio** — most theoretically grounded for DKS assessment, captures something no single-digit test does
- **Composite** — weighted combination of multiple levels
